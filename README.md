# 📚 图书管理系统

一个基于 Python 命令行的图书馆管理系统，支持图书的增删改查、借阅与归还，数据自动持久化保存。

---

## 环境要求

| 依赖 | 版本 |
|------|------|
| Python | **≥ 3.10** |

无需安装任何第三方库，全部使用 Python 标准库。

---

## 如何运行系统

### 1. 获取代码

```bash
git clone https://github.com/202312063034/test.git
cd test
```

### 2. 启动交互式菜单

```bash
python main.py
```

启动后将看到以下主菜单：

```
============================================================
          📚  图书管理系统  📚
============================================================
  1. 添加图书
  2. 删除图书
  3. 修改图书信息
  4. 查看所有图书
  5. 搜索图书
  6. 借出图书
  7. 归还图书
  8. 查看借阅记录
  0. 退出系统
============================================================
请输入操作编号:
```

按照提示输入编号即可完成对应操作。数据会自动保存到当前目录下的 `library_data.json` 文件中，下次启动时自动加载。

---

## 功能说明

| 编号 | 功能 | 说明 |
|------|------|------|
| 1 | 添加图书 | 输入书名、作者、ISBN、馆藏数量 |
| 2 | 删除图书 | 按图书 ID 删除（有未归还副本时拒绝删除） |
| 3 | 修改图书信息 | 可单独修改书名、作者、ISBN 或馆藏数量 |
| 4 | 查看所有图书 | 列出全部馆藏图书及可借数量 |
| 5 | 搜索图书 | 支持按书名关键词 / 作者关键词 / ISBN 精确查找 |
| 6 | 借出图书 | 输入图书 ID 和借阅人姓名，生成借阅记录 |
| 7 | 归还图书 | 输入借阅记录 ID 完成归还 |
| 8 | 查看借阅记录 | 查看全部 / 按借阅人 / 仅未归还记录 |
| 0 | 退出系统 | 安全退出 |
